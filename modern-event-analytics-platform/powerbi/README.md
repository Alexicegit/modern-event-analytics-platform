# Power BI Dashboard Guide

Create the following pages in Power BI:

## Page 1: Executive Overview
- Total Revenue
- Tickets Sold
- Average Order Value
- Revenue by Month
- Top 10 Events

## Page 2: Event Performance
- Revenue by Category
- Tickets Sold by Event
- Capacity Utilization
- Event Location Map

## Page 3: Customer Analytics
- Revenue by Customer Segment
- Customer Count by Country
- Repeat Purchase View

## Page 4: Reseller Performance
- Revenue by Reseller
- Ticket Volume by Channel
- Commission Rate Analysis

Recommended dataset source: Snowflake MART schema.
